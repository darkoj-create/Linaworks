PRACTICAL QUESTIONS

Clear expectations from the start.

How is pricing determined?

By agreed scope, complexity and integrations. The proposal sets out the price and any licence costs before work begins.

Do we need to provide system access immediately?

A workflow description is enough for the first conversation. Access and data handling depend on the agreed scope; pilots can use anonymised or sample data.

What is included in handover?

The agreed solution and usage instructions. Documentation, source code handover, ownership and usage rights are defined in the proposal.

What about support after handover?

We agree how issues are reported, a correction period and any ongoing maintenance before starting the project.
